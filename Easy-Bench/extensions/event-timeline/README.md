# Event timeline

Дополнительная задача Easy-Bench по мотивам Q06 из [Objective Workbench v3](https://github.com/teo-nex/TeoBench/pull/17). Модель восстанавливает цепочку попыток по логам с общим идентификатором запроса, учитывая часовые пояса, поправки часов сервисов и исправленные записи. Во входных данных есть переход через полночь UTC, событие на границе ретрая и попытка без ответов.

Передайте модели только [условие и входные данные](public). Сохраните её JSON-ответ в файл и запустите из корня репозитория:

```sh
python3 Easy-Bench/extensions/event-timeline/grade.py /path/to/submission.json
```

Оценщик возвращает `PASS` с кодом 0 или `FAIL` с кодом 1. Порядок ключей и пробельные символы в JSON произвольны. Порядок элементов массивов, типы и значения должны совпадать с эталоном.

Эталон опубликован для воспроизводимости. Задача оценивается отдельно от замороженной кампании Easy-Bench из 30 задач.
