# Статистика Easy-Bench

[summary.json](summary.json) — машинный формат; [summary.csv](summary.csv) — таблица для анализа. Файлы автоматически обновляются после принятия исследований в `main`.

Одна строка объединяет только полные запуски с одинаковыми моделью, effort, маршрутом, окружением и версией оценщика. Одна попытка/повтор — 30 задач; среднее и медиана считаются по долям пройденных задач в таких запусках. Неполные условия исключаются. Точные копии наборов ответов не считаются новыми исследованиями.

`grader_sha256` сохраняет исходную версию оценщика из исследования; `regraded_with_sha256` указывает версию, которой фактически перепроверены ответы. Для прежнего macOS-оценщика разрешена только явно указанная в коде пара совместимости с Linux-оценщиком. Все сохранённые оценки должны совпасть при перепроверке; файлы исследований и их исходные хеши не меняются. Новые записи и отправки требуют текущую версию оценщика. Подробности — в [протоколе](../../docs/PROTOCOL.md#historical-grader-compatibility).

`transport_errors` показывает число незавершившихся запросов; они входят в знаменатель полного запуска, но сохраняются отдельно. Частичные баллы отдельных тестов не заменяют балл всей задачи. Время не сводится в общий рейтинг: оборудование, очереди и бюджеты различаются.

Независимо перепроверяются ответы. Метки модели, условия inference, происхождение вызовов инструмента и отсутствие доступа к эталонам сообщаются автором отчёта. В этой статистике нельзя интерпретировать число исследований как размер случайной выборки пользователей или как доказательство деградации модели.

Локальное воспроизведение из корня репозитория:

```bash
python3 -m teobench stats --output Easy-Bench/statistics/summary.json
```
