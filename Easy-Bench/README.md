# Easy-Bench

**Default research / Полное исследование: 7 models × 5 efforts × 30 tasks = 1050 primary trials, plus 35 pilot and 42 control trials. Thirty tasks on one model are only one condition.** Read [the full-study guide](../docs/RUN_FULL_STUDY.md) and [campaign.json](campaign.json).

Первый уровень TeoBench: 30 неизменённых задач исследования reasoning effort сентября и ноября 2026 года. Название Easy относится ко всему уровню, а не только к десяти задачам с исходной меткой `easy`.

| Папка | Содержание |
|---|---|
| [tasks](tasks) | `tasks.jsonl`, публичные эталоны `answers.json`, исходный manifest и генератор |
| [studies](studies) | Принятые исследования: `<study-id>/study.json` |
| [statistics](statistics) | Статистика полных запусков сообщества |
| [research-2026-11-03](research-2026-11-03) | Исправленные и исходные оценки первого исследования |

По шесть задач `R01–R06`, `C01–C06`, `S01–S06`, `D01–D06`, `T01–T06`. Просмотр: `python3 -m teobench show R01` из корня проекта. Каталог всех формулировок: [TASKS.md](TASKS.md).

В Python опубликованы 300 тестовых входов, включая шесть примеров из условий. SQL проверяется на 72 базах. Раньше эти данные были скрыты от модели, теперь они доступны для воспроизведения. Во время честного прогона модель получает только задачу и предусмотренные результаты инструмента.

Короткие точные ответы, функции, SQL-запросы и цепочки lookup проверяются автоматически. Качество длинных документов, произвольная работа с GUI и реальные производственные проекты этим уровнем не измеряются.
